2. **The 3-Step Cognitive-Behavioral Framework (Reflect, Release, Recharge)**: Structural progression through present-moment reflection, physical decompression/breathing, and positive intention setting.

### Core Architectural Improvements & `<div>` Rationale

1. **Outer Viewport Shell (`<div class="app-viewport">`)**: Encapsulates the entire application, centering `<main class="app-canvas">` with an unbreakably locked $4:5$ Instagram-style frame ratio. Setting `overflow: hidden` on the outer shell guarantees zero document scrolling across all screen types.


2. **Single Focal Stage Cards (`<div class="wellbeing-container">`)**: Encapsulates active elements within a dedicated card container inside each `<section>`. This isolates visual focus to a single card node per step, reducing visual noise and shielding executive function.


3. **Dedicated Animation Decorator Nodes (`<div class="breathing-guide">`)**: Keeps purely decorative somatic animations (such as the 10-second rhythmic breathing visualizer) cleanly separated from reading text nodes. Decorator `<div>` tags are hidden from screen readers using `aria-hidden="true"`.


4. **Accessible Microcopy Overlays (`<output>` / `<dialog>`)**: Implements semantic HTML controls like `<output>` for live timer feedback and native `<dialog>` overlays for optional settings, keeping main focus uncluttered.
